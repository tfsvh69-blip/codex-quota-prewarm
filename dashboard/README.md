# Codex 账号管理台（本地网页 MVP）

这是运行在 Windows 本机的上位机页面，不需要安装 Vue/React，也没有云端服务和数据库。

## 打开

默认访问：http://127.0.0.1:38671/

启动服务：在仓库根目录运行 node dashboard/server.js。或运行 scripts/install-dashboard.ps1 注册登录后自动启动任务。安装服务不会改动既有 Codex 晨间/白天定时任务。

如果现役调度器不在本仓库目录，可以在仓库根目录创建 .dashboard.local.json，内容为：

    {
      "port": 38671,
      "schedulerRoot": "C:\\path\\to\\Codex额度预激活"
    }

schedulerRoot 是现役 accounts.json 的文件夹路径。此私有文件已 Git 忽略。

## 功能

- A/B/C/D 等账号槽位：登录邮箱、登录状态、重复身份提示、五小时额度、每周额度、下一次重置时间。
- 槽位新增/启用/停用：写入现役 accounts.json，原调度器下次执行时自动读取。A 主账号不允许停用。
- 登录或更换账号：走官方 Codex app-server 的 ChatGPT 浏览器 OAuth 流程。登录链接仅发送给本地页面，不写磁盘。用户需亲自完成授权；如浏览器自动选择旧账号，请在无痕窗口选择正确账号。
- 选择「当前操作账号」：仅影响本页面当前槽位；「打开终端」会以这个槽位的 CODEX_HOME 启动独立 Codex CLI 会话。
- 最近调度记录：从现役日志中提取各槽位的简短条目，当前只读，不发送真实模型请求。
- Windows 开机登录自动启动：任务名称 Codex-额度管理上位机，浏览器快捷方式为桌面 Codex额度管理台.url。

注意：选择上位机「当前操作账号」**不会**切换已经运行的 Codex 桌面应用、VS Code 扩展或其它命令行进程的账户；不会修改默认的 A 主账号凭据。

## 安全

只监听 127.0.0.1，HTTP Host/Origin 受限，修改请求要求每次启动生成的会话令牌，页面不显示或保存登录 Token。不能直接把 38671 端口映射到公网。每个账号的凭据只保存在自身 CODEX_HOME 下。

官方 app-server 接口文档：https://learn.chatgpt.com/docs/app-server

## MVP 验证

在运行中的电脑上查看：
- HTTP 200：页面 HTML/JS/CSS。
- 官方接口能分别查询 A/B/C 邮箱及额度；若重复登录会标记重复身份。
- 当前操作 A→B→A 切换后重载保持一致。
- 新增/启用槽位并停用后，配置可恢复；测试时无需删除凭据。
- 未登录测试槽位可启动 OAuth 授权链接并取消，不自动消耗额度。
- 原有 Windows 定时任务应保持不变。

已知限制：服务器只在已登录的 Windows 用户环境运行；浏览器未授权时，登录状态为等待；遇到代理或官方服务异常，额度查询会给出错误状态。UI 只作为调度可视化，不保证重置窗口的时间永远固定。
